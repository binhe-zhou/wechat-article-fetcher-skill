# 排障手册

排查顺序建议：先确认环境与账号前置条件，再定位控件层问题，最后检查解析链路。

## 环境类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| `当前系统为 Darwin / Linux` | 非 Windows 主机 | 链接采集必须迁移到 Windows；解析类 tool 可继续使用 |
| `微信客户端版本为 4.1.x.x` | 注册表解析出的版本不是 4.1.8.101 | 安装/回退到 4.1.8.101；`mmui::*` 控件树与该版本绑定 |
| `无法读取微信客户端版本` | `HKCU\Software\Tencent\Weixin` 的 `Version` 缺失 | 确认已安装并运行过微信 4.1.8.101；版本号从注册表读取 |
| `微信客户端未启动或未登录` | 进程或 `mmui::MainWindow` 未找到 | 启动并登录微信 4.1.8.101 |
| `缺少依赖：pywinauto, win32gui…` | 未安装 Windows 依赖 | `python -m pip install -r requirements.txt` |
| `缺少 MCP SDK` | 未安装 `mcp` / `fastmcp` | `python -m pip install mcp` |

**注意：环境自检不输出「讲述人未运行」「UIA 控件树不可见」「账号未订阅」这三类问题。** 它们是使用提示，不是校验项，不会阻断 `get_article_links`。

## 链接采集类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| **登录账号未订阅目标公众号/服务号** | 采集依赖微信客户端内搜索并进入公众号主页；未关注或已取消关注时账号不出现在搜索结果/会话中 | **先在当前登录的微信账号中关注该公众号或服务号**，确认能在微信里打开其主页与「文章」标签后再执行；见下方说明 |
| `NoResultsError: 查无此公众号!` / `在搜索结果列表中未找到名称【x】的公众号` | 名称不完全一致（简繁体、空格、后缀）、列表未加载，或**账号未订阅** | 复制微信内显示的准确全称，确认已订阅；必要时增大 `GlobalConfig.load_delay` |
| `NotFoundError: 点击资料图标后，公众号主页窗口未弹出` | **公众号名称未在 `OFFICIAL_ACCOUNT_TYPE_MAP` 登记**，账号类型返回 `None`，`title` 定位失败；也可能是未订阅导致主页未打开 | 在 `wechat_runtime.py` 的映射表登记「公众号」或「服务号」，或调用 `GlobalConfig.register_official_account()`；同时确认已订阅；主页窗口按精确标题定位，请勿改用模糊匹配 |
| `NotFoundError`（默认消息：无法识别微信主界面） | `Tools.get_weixin_hwnd()` 未筛到 `mmui::.*Window` | 确认微信已登录、UIA 控件树可见 |
| `公众号会话窗口未正常打开` | 会话窗口标题不含公众号名，或未订阅导致没有会话入口 | 确认已订阅、公众号全称与微信语言；检查窗口类名是否随客户端版本变化 |
| `未找到公众号主页入口按钮` | 标题栏可见 Button 为空 | 保持微信前台、检查 UIA 控件树（建议开启讲述人） |
| `公众号主页找不到【文章】标签` | 客户端 UI 变化、页面未加载完，或未订阅时进入的是资料页而非主页 | 确认已订阅并能正常打开主页；增大 `GlobalConfig.load_delay`；确认微信 4.1.8.101 |
| 控件定位失败 / `ElementNotFoundError` | 讲述人未开启、微信未前台、账号受无障碍策略限制 | 建议 `Win + Ctrl + Enter` 开启讲述人、保持微信前台已登录；**不做前置校验** |
| 剪贴板为空 / 链接未采集 | 「更多 → 复制链接」菜单项位置变化 | 检查 `AppMenuButton` 与两次 `{DOWN}` 后是否为「复制链接」；该定位与客户端版本强相关 |
| `ElementNotFoundError` / `TimeoutError` / `ComError` | 控件树刷新、窗口被手动关闭、微信被切到后台 | **不要自动重试**；结束任务并把失败控件与原因反馈给用户 |
| 采集持续滚动不结束 | 页面日期分组文本未被识别，或历史文章未到起始日期 | 循环仅靠「分组日期早于起始日期」终止，没有滚动上限。先缩小日期区间，检查页面日期格式是否覆盖 |
| `count == 0` | 该区间确无文章、日期分组识别失败，或**未订阅导致主页无文章列表** | 先确认已订阅且主页「文章」标签可见；用较宽区间验证；检查日期解析正则 |

**账号订阅前置条件（仅提示，不校验）**：链接采集走的是微信客户端内「搜索公众号 → 打开会话 → 进入主页 → 文章标签」这条路径。**当前登录的微信账号必须提前关注（订阅）目标公众号或服务号**，否则搜索结果通常不出现该账号，或无法打开带「文章」标签的主页，常见表现为 `NoResultsError` / `NotFoundError` / `count == 0`。该状态无法由程序可靠判断，因此**没有写入 `check_environment()`**，需由用户在执行前自行确认。标题 / 发布时间 / 正文解析不受此限制，可直接处理用户提供的链接。

## 文章解析类

| 现象 | 原因 | 处置 |
| --- | --- | --- |
| `仅支持 mp.weixin.qq.com 域名下的公众号文章链接` | 链接被裁剪、带多余字符或来自其它域名 | 使用 `get_article_links` 返回的原始链接 |
| `返回内容过小` | 链接失效、被删除或访问受限 | 浏览器打开链接核验 |
| `触发微信安全验证` | 触发滑块/环境异常校验 | 人工在浏览器打开并完成验证后重试 |
| `未能解析到标题与正文` | 文章删除、页面结构改版 | 用 `scripts/fetch_article.py --url <链接>` 调试，检查解析正则 |
| 正文不完整 / 被截断 | `js_content` 内嵌套 `</div>` 使正则提前结束 | 调整 `article_parser.parse_content` 的截断模式 |
| 发布时间为 `0` | 页面未提供 `var ct` 等三种字段 | 检查页面 HTML；可补充新的时间字段正则 |
| 抓取超时 | 网络不可达或被限流 | 检查网络；必要时增大 `fetch_article(timeout=...)` |

## 调试顺序

1. `python scripts/check_environment.py` —— 确认平台、注册表版本 4.1.8.101、微信进程与依赖。
2. 确认登录的微信账号**已订阅**目标公众号/服务号（不做代码校验），且公众号名称已在 `OFFICIAL_ACCOUNT_TYPE_MAP` 登记（主页窗口 `title` 的唯一来源）。
3. `python scripts/fetch_article.py --url <用户提供的真实链接>` —— 单独验证解析链路。
4. 解析正常但采集失败 → 先复查订阅状态，再聚焦 UIA 控件树可见性（建议开启讲述人、保持微信前台）与客户端版本。
5. 查看 MCP Server 的 stderr 日志；stdout 只承载协议报文。

## 原则

- UI 自动化异常不自动重试，由用户决定是否重跑。
- 不编造数据：任何一步失败都要在结果中显式标注。
- 采集频率保持克制，避免高频翻页触发微信风控。
